## ✨ Features

- 🌍 **Bilingual** — English & Arabic with automatic RTL / LTR switching
- 🌓 **Dark & Light modes** — respects system preference on first visit
- 💾 **Persistent** — theme and language saved in `localStorage`
- 📱 **Fully responsive** — mobile, tablet, and desktop
- ♿ **Accessible** — semantic HTML, ARIA labels, focus states
- 🎨 **Themeable** — all colors & spacing driven by CSS variables
- ⚡ **Zero dependencies** — no npm, no bundler, no framework
